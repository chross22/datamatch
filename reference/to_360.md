# Convert a longitude to the 0-360 convention CCMP uses

CCMP is the one source in this package on a 0-360 grid; Copernicus,
HYCOM and FVCOM all run -180 to 180. A Northwest Atlantic box asked for
as -70 to -66 would select nothing here, or — worse, if it were clamped
rather than rejected — a stretch of the Indian Ocean.

## Usage

``` r
to_360(x)
```

## Arguments

- x:

  longitudes in either convention

## Value

the same longitudes in 0-360

## Details

So the box is converted on the way in and the coordinates converted back
on the way out, and what a caller passes and receives is negative west
throughout, as with every other source.
