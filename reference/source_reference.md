# The citation for a source tag such as `"hycom:GLBv53X"`

The citation for a source tag such as `"hycom:GLBv53X"`

## Usage

``` r
source_reference(tag)
```

## Arguments

- tag:

  a tag as
  [`source_of()`](https://chross22.github.io/datamatch/reference/source_of.md)
  returns

## Value

the reference, or `NA` when the source carries none
