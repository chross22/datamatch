# Values a raster or colour scale can take

Factors are plotted by their level codes, so a categorical column such
as the `<var>_source` that
[`fill_satellite_gaps()`](https://camilleross.org/datamatch/reference/fill_satellite_gaps.md)
adds can be mapped rather than erroring.

## Usage

``` r
numeric_for_plot(x)
```

## Arguments

- x:

  a column

## Value

numeric
